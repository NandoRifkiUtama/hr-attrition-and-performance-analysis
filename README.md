# HR Attrition & Performance EDA

## Overview
This project focuses on Exploratory Data Analysis (EDA) of an HR Attrition and Performance dataset sourced from :contentReference[oaicite:0]{index=0}. Using SQL in Google BigQuery, I explored employee demographics, workforce composition, attrition trends, and performance-related metrics to identify patterns and generate business insights.

## Objectives
- Understand workforce demographics
- Measure employee attrition rates
- Identify departments and job roles with high turnover
- Explore relationships between attrition, satisfaction, and performance
- Generate insights to support employee retention strategies

## Dataset
Source: HR Attrition and Performance Dataset from Kaggle

## Tools
- Google BigQuery
- SQL
- GitHub

## Analysis Performed
### Workforce Overview
- Total employees
- Active vs. attrited employees
- Employee distribution by department

### Attrition Analysis
- Overall attrition rate
- Attrition by department
- Attrition by job role
- Attrition by age group
- Attrition by gender

### Employee Characteristics
- Education level distribution
- Marital status analysis
- Years at company
- Monthly income distribution

### Performance Analysis
- Performance rating distribution
- Job satisfaction analysis
- Work-life balance analysis
